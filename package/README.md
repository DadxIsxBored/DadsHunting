# DadsHunting

DadsHunting adds a target emblem beside the PvP swords in Valheim's inventory header. The **Select your Quarry** menu lists qualifying animals the character has killed, grouped by biome. Select one quarry at a time.

When the selected animal spawns within the configured detection range, DadsHunting displays Valheim's raid-style red circle over its general location. The default detection range is 50 meters and the default circle diameter is 25 meters. The circle disappears 30 seconds after the player enters it.

Install with BepInExPack for Valheim. Set detection range and circle diameter in `BepInEx/config/com.dadisbored.dadshunting.cfg`.
