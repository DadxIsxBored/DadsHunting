# DadsHunting

DadsHunting adds a target emblem beside the PvP swords in Valheim's inventory header. The **Select your Quarry** menu lists qualifying animals the character has killed, grouped by biome. Select one quarry at a time.

When a spawned object record for the selected animal has a live game object within the configured detection range, DadsHunting displays Valheim's raid-style red circle at the object's current position and updates the circle as the animal moves. The default detection range is 50 meters and the default circle diameter is 25 meters. The circle disappears 30 seconds after the player enters it.

Install with BepInExPack for Valheim. Set detection range and circle diameter in `BepInEx/config/com.dadisbored.dadshunting.cfg`.
